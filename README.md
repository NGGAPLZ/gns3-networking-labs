# GNS3 Networking Labs

Portfolio maintained by **NGGAPLZ**. Hands-on networking coursework covering
static routes, MAC learning, ARP, IPv4/IPv6 routing, and VLAN isolation.

| Lab | Included material | Status |
|---|---|---|
| [Four-router static routing](static-routing/README.md) | GNS3 topology, four router configs, four VPCS startup files, original evidence | Configurations checked offline; simulator not rerun |
| [Switching, dual-stack routing, and VLANs](switching-routing-vlans/README.md) | Anonymized collaborative lab report, addressing tables and findings | Historical reported results; project files were not supplied |

The static-routing lab is the most complete reproducible artifact. The second
report comes from joint coursework; individual contributions were not recorded
in the supplied material, so it is not presented as solely authored work.

Use these in an isolated lab. The saved IOS configs include lab conveniences
such as privileged console access and disabled console timeouts, and are not
production hardening templates. Router operating-system images are not included.

## Contents and provenance

Original screenshots show historical results, not fresh simulator runs. Text,
filenames and device aliases in the collaborative write-up have been anonymized.
The collaborative screenshots were omitted because they expose another student's
name. No new screenshots or successful test results have been fabricated.

See [preparation notes](PREPARATION.md) for the small configuration repairs.
